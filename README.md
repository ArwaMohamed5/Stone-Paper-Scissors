# Stone Paper Scissors (C++)

A console Stone-Paper-Scissors game written in C++ where you play against the computer.

## Features
- Choose how many rounds to play (1 to 10)
- Round-by-round results and a final game summary
- Colored screen and a sound effect depending on the winner
- Play again option

## How to Play
1. Enter the number of rounds.
2. Each round, choose: 1 = Stone, 2 = Paper, 3 = Scissors.
3. The computer picks randomly, and the winner of each round is shown.
4. At the end, the overall winner is displayed.

## Build and Run
1. Open `Stone-Paper-Scissors-cpp.sln` in Visual Studio.
2. Press `Ctrl + F5`.

> Windows only: the game uses `system("color")` and `system("cls")`.

## Concepts Used
Enums, structs, functions, `rand()` and `srand()`, input validation, loops.
